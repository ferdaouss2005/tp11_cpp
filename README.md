# tp11_cpp

EXERCICE1

<img width="256" height="205" alt="image" src="https://github.com/user-attachments/assets/e1cd6907-8e49-49c7-be85-9fa529b4cf92" />

Dans cet exercice, j'ai découvert l'interface List et son implémentation ArrayList en Java à travers une application de gestion d'une liste de courses. J'ai utilisé les méthodes add() pour ajouter des articles, remove() pour supprimer un article, contains() pour vérifier sa présence et size() pour obtenir le nombre d'éléments dans la liste. J'ai également utilisé une boucle for-each pour afficher les articles dans leur ordre d'insertion.

EXERCICE2


<img width="316" height="121" alt="image" src="https://github.com/user-attachments/assets/76170a9a-3b16-4875-9c8d-b13bde1c4494" />

Dans cet exercice, j'ai créé une classe Task contenant les attributs title et completed pour représenter une tâche. J'ai ensuite développé une classe TaskManager utilisant une ArrayList pour stocker et gérer plusieurs tâches. J'ai utilisé les méthodes add() pour ajouter des tâches, get() pour accéder à une tâche et setCompleted() pour modifier son état. Enfin, j'ai redéfini la méthode toString() pour afficher chaque tâche avec son état : terminée ou non terminée.

EXERCICE3

<img width="394" height="88" alt="image" src="https://github.com/user-attachments/assets/e006027d-2e42-4905-a548-539ce5851238" />

Dans cet exercice, j'ai découvert l'interface Set et ses différentes implémentations en Java : HashSet, LinkedHashSet et TreeSet. J'ai utilisé HashSet pour stocker des éléments sans doublons et sans ordre garanti, LinkedHashSet pour conserver l'ordre d'insertion et TreeSet pour trier automatiquement les éléments par ordre alphabétique. Cet exercice m'a permis de comprendre les différences entre ces trois structures de données.

EXERC5CE 5

<img width="639" height="129" alt="image" src="https://github.com/user-attachments/assets/ce00eac4-516f-4994-acd8-6b5c746f5995" />

Dans ce TP, j'ai découvert et manipulé les principales structures de données de l'API Collections de Java. J'ai utilisé List avec ArrayList pour gérer des listes d'articles et des tâches, Set avec HashSet, LinkedHashSet et TreeSet pour stocker des éléments uniques et comprendre les différents comportements d'ordre, ainsi que Map avec HashMap pour associer des clés à des valeurs dans un dictionnaire bilingue. Enfin, j'ai réalisé une application de gestion de bibliothèque en utilisant plusieurs collections pour gérer les livres, les catégories, la recherche par ISBN, les emprunts et les restitutions. Ce TP m'a permis de mieux comprendre le fonctionnement et l'utilisation des collections en Java.
